## Themes and what to build

Themes are optional. Any project can win 1st, 2nd, or 3rd place; only a themed project can win a theme specialty award. Use what makes quantum computing unique, not just a random number generator.

| Theme | The challenge |
| :---- | :---- |
| Quantum Impact | Solve a real world problem with a hybrid quantum and classical approach. Build a strong classical baseline, then show where a quantum subroutine improves solution quality, efficiency, or accuracy. |
| Quantum Playground | Build something playful, artistic, or unexpected, such as a game, music, art, or an interactive experience where superposition, interference, entanglement, or measurement is essential. |
| Quantum Unlocked | Make a hard quantum concept click through an interactive demo, animation, or visualization, such as error correction, fault tolerance, quantum networking, or a specific algorithm. |

Every submission must show at least one of: a novel application of an existing technique to a new domain, a technical extension (noise or error mitigation, optimization, benchmarking), or an original analytical or educational contribution. Missing this bar can mean a 0 on Novelty and Technical Execution.

## Judging, prizes and rules

Two rounds, same four criteria. Your node's 3 local judges score every submission first; a global panel scores the top 3 from each node, plus up to one project per specialty category, a second time.

| Criterion | What judges look for |  |  |  |
| :---- | :---- | :---- | :---- | :---- |
| Novelty and Creativity | An original idea or approach, not a standard tutorial or well known demo |  |  |  |
| Technical Execution | Correct, well built code that runs and does what it claims |  |  |  |
| Impact Potential | Whether it could matter beyond the hackathon, for research, education, industry, or the community |  |  |  |
| Documentation Quality | Whether others can understand, run, replicate, and extend it |  |  |  |
|  | **1st** | **2nd** | **3rd** | **Specialty** |
| Local (10+ submissions): cash / credits | \$500 / \$5,000 | \$300 / \$3,000 | \$200 / \$2,000 | N/A |
| Global: cash / credits | \$10,000 / \$20,000 | \$5,000 / \$15,000 | \$2,500 / \$10,000 | \$500 / \$5,000 |

Specialty awards: Most Novel/Creative, Best of each theme, Most Impact, Best Documentation; a project can win both a placement and a specialty award. Select teams may also get mentorship sessions, sponsor interviews, or extra credits. Nodes may add local prizes such as course credit.

**Rules to know:**

* Using AI tools, open source libraries, tutorials, or Qollab templates is fine, as long as you disclose and attribute them.

* Disqualifiable: work that already existed, uncredited copying, an undisclosed template, a nearly identical submission to another team's, or misrepresented authorship.

* Standard code of conduct applies; your site lead enforces it locally.

* By participating you agree to: MIT license, keeping the project live on Qollab for 12 months, the attribution line, a valid payment method if you win, and, if you win, being featured by Qollab and IonQ, handling your own taxes on the award, and one social post about participating.

* Scores and awards are final, except disqualification, appealable to hackathon@qollab.xyz within 24 hours; a separate reviewer decides within 5 business days.

If the platform goes down, we'll post updates in \#hackathon-help. An outage over 12 hours during the build window may mean an extended deadline for all nodes, or late submissions accepted with a short impact note. Short or intermittent issues, and problems limited to your own setup, don't qualify for an extension. Tip: test locally where you can, to stay off the shared simulator queue while debugging.

**A couple more things:** your data is used only to run the hackathon and the Qollab platform, per the privacy policy at qollab.xyz/privacy. Multiple submissions are fine; each is judged on its own, and the project stays live and forkable on Qollab for at least 12 months either way.
